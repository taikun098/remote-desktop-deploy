# remote-desktop-deploy

Linux 主机远程桌面环境（xrdp / VNC / noVNC / EasyTier 组网 / Steam 与输入法）部署与排障脚本集。

## 目录说明

- `rd_*.sh` / `rd_*.py` — 远程桌面安装、配置、状态检查、日志抓取
- `ss_*.sh` / `et_*.sh` — 服务与组网（EasyTier）相关
- `fc_*.sh` / `i18n_*.sh` / `hid_*.sh` — Fcitx5 输入法、桌面图标、壁纸环境
- `*_out.txt` — 上述脚本在板端/服务器上的实际输出（归档留证）

## 说明

本仓库为脱敏存档：账号、密码、主机名等凭据已移除，用户名统一替换为 `user`。
